# Poo & Flow Tally

A cute single-page tracker to tally daily poops, connect them to menstrual cycles, and get gentle reminder nudges.

## Features
- Quick "I just went" button to increment today's count.
- Local storage keeps daily tallies and cycle info private on your device.
- Lightweight 14-day chart highlighting period days to visualize patterns plus a clear 7-day calendar snapshot.
- Insight text summarizing differences between period and non-period days.
- Optional Notification API reminders every few hours while the tab stays open.
- Pastel bubble buddies inspired by soft vinyl characters for warm vibes.

## Usage
Open `index.html` in a modern browser. Optionally enable notifications when prompted to get tally reminders.
